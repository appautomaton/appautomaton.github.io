# Pi Arcweld website module

Public mount: `/pi-arcweld/`. Static source: `public/`.

Imported from [appautomaton/pi-arcweld at 7dc826f5](https://github.com/appautomaton/pi-arcweld/tree/7dc826f59fd3a7d9353c99be77841d8e0747bdef/docs),
matching [the successful publication](https://github.com/appautomaton/pi-arcweld/actions/runs/34552774608).
The initial nine published files are byte-identical to that artifact. The source
`.nojekyll` is retained but excluded by the adapter to match the original uploader.

Use the root build and preview commands. `public/og-card.html` is the rendering
source for the social card, not a content route for the sitemap. Runtime
extensions and technical source stay in the Pi Arcweld repository.

See [the design boundary](DESIGN.md) and imported [license](LICENSE). The original
project Pages publisher remains authoritative during this preview pilot.
