Setloom

Setloom is an open-source agentic music producer. You direct in plain language and judge by ear. A coding agent composes, renders, and revises the music as editable source.

Get Setloom on GitHub Listen on SoundCloud

Keep the ear. Hand the studio to the agent.

Setloom moves music production out of the DAW and into source code that a coding agent writes and renders. You still need a terminal and a frontier model. You no longer need the piano roll, the plug-in chain or the mixing vocabulary. What stays with you is the judgement: hearing a pass and saying what is wrong with it.

AWhat it is

What is Setloom?

Setloom is an open-source harness that lets a coding agent, such as Codex or Claude Code running a frontier model, produce music under a person's direction. The person describes the music and judges each audition by ear. The agent writes each track as editable source (MIDI performances, instrument settings and a renderer), renders it, inspects the result, and revises it. Setloom is made by App Automaton.

BHow it works

How does Setloom work?

Setloom splits music production into three roles: the person directs, the agent produces, and the harness supplies the studio tools.

Youthe listener and creative director

You give direction in plain language, for example the bass is too busy before the break, make the arp darker, and you accept or reject each audition.

The agentthe producer

The agent makes the musical choices within the brief, writes each track's source, renders an audition, inspects it, and revises rejected work. Measurements never override your verdict.

The harnessthe studio

The harness provides audio inspection, transcription, stem separation, MIDI and mastering tools, and keeps every render reproducible. It composes nothing.

CThe loop

Audition, react, revise.

Each pass goes once round the same six-step loop.

  1. Step 1 of 6DescribeYou describe the music you want, in plain language.
  2. Step 2 of 6Edit the sourceThe agent edits the track's source: its MIDI, instruments and renderer.
  3. Step 3 of 6Render an auditionThe agent renders the source to audio.
  4. Step 4 of 6Play and inspectThe agent plays the audition and inspects its waveform, spectrum and rhythm.
  5. Step 5 of 6Listen and noteYou listen and say what is wrong, in plain words.
  6. Step 6 of 6Revise or keepThe agent revises the source and goes round again, or you keep the track.

Scroll to go round the loop

Measurements inform the agent. The verdict is always the person's.

DWhat it does

What can Setloom do?

Setloom gives a coding agent command-line tools and Python modules for every stage of music production. The agent uses them as each track needs. There is no fixed sequence.

Compose and arrange
Each track keeps its own MIDI performance, instruments and renderer.Python, mido, SuperCollider
Transcribe audio to MIDI
setloom transcribe recovers notes and pitch bends.Basic Pitch, running natively on MLX in FP32
Transcribe piano
setloom transcribe --engine kong recovers piano notes.Kong piano transcription
Separate stems
setloom separate writes every stem estimate as float WAV.A 53-stem BS-RoFormer model, converted to run natively on MLX
Inspect audio
setloom inspect plots waveform, spectrogram, spectrum, stereo and rhythm, with A/B comparison.NumPy, SciPy
Master for release
setloom.audio measures loudness and applies true-peak limiting.FFmpeg, pyloudnorm
Audition
setloom play plays a render on request, never automatically.macOS audio
Drive instruments
The agent plays SuperCollider, Ableton Live and Logic Pro and records the settings.Ableton Live through an MCP bridge

FInstall

What do you need to run Setloom?

Setloom needs a frontier model running in a coding agent. It is a harness for that agent, not a standalone app, and does not produce music without one.

  • A coding agent running a frontier model, such as Codex or Claude Code
  • A Mac with Apple Silicon
  • Python 3.11 or newer and uv

How do you install Setloom?

Setloom installs into one repository-local uv environment in three commands.

Terminal
# clone the repository and set up its one environment
$ git clone https://github.com/appautomaton/setloom.git
$ cd setloom
$ uv sync --group transcription

# then open your coding agent here and describe the track you hear

The coding agent reads the repository's AGENTS.md and chooses its tools. Full setup is in the README.

How is Setloom different from AI music generators?

Setloom produces editable source that a person revises pass by pass, while prompt-to-song generators such as Suno and Udio return finished audio from a text prompt.

Frequently asked questions

Is Setloom free?
Setloom is free and open source under AGPL-3.0-only. The frontier model that drives it is billed by its provider.
Is Setloom a one-click music generator?
Setloom is not a one-click generator. A person stays in the loop as the listener, and each pass turns their notes into specific changes to the track's source.
Do I need a DAW to use Setloom?
Setloom does not require a DAW. The user never operates a DAW or plug-in. The agent can drive SuperCollider, Ableton Live or Logic Pro when a track calls for them.
Which coding agents work with Setloom?
Setloom works with coding agents that read repository instructions, such as Codex and Claude Code. It needs a frontier model.
Does Setloom run on Windows or Linux?
Setloom is developed for macOS on Apple Silicon. Its transcription and stem separation run on MLX, which requires Apple Silicon.
Can Setloom remix or rebuild an existing song?
Setloom can transcribe and separate a recording, rebuild it as an editable performance, and reinterpret it. Using someone else's recording remains subject to its rights.
What kind of music can Setloom make?
Setloom has no built-in genre. Released work includes electronic tracks, remixes and solo piano.
Who owns music made with Setloom?
The person owns the music, subject to the samples, models and inputs they bring. Setloom's code is AGPL-3.0-only and its documentation is CC BY-SA 4.0.
